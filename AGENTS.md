# Vignette updates

When adding or changing a vignette, follow [docs/VIGNETTE_RELEASE_CHECKLIST.md](docs/VIGNETTE_RELEASE_CHECKLIST.md). Review its personal Witness resolution, shipped story registration, resulting threshold, tests and current documentation as part of the same change.

Witness requires 75% of the playable, eligible story pool, rounded up, across at least two story kinds. Keep the quota derived from `WitnessAccount.Story`, rather than freezing it to a number. Only fully playable sources with an actual personal resolution belong in that pool. Separate choices within one vignette count once. Preserve stored evidence and completed endings when growing the pool.

Current 0.4.14 baseline: eight eligible stories, six required resolutions, three ending options. Update these documented counts with each vignette release. Growl reactivity is an exploration system and does not add a Witness source.
