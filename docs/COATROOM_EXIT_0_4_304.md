# The coatroom exit and story pacing

Once the coatroom has its answer, both the screen door and the curtain lead into the ordinary hall that was dealt to the source door. The screen door previously sent the reader back to the source side. Both exits play the coatroom's closing line and restore the reader's own gear. The onward hall keeps one return to the source door.

The default story guarantee takes effect after four eligible dry deals. The next eligible deal offers a story when the usual spacing and availability rules allow it. A saved server configuration still uses its `exploration.storyDryGuarantee` value.

The native coatroom test checks the screen door, closing card, restored inventory and landing in the dealt hall after a saved-data reload. The domestic pacing test checks the chance at three eligible misses and the guarantee at four.
