# Goatman supper testing shortcut, 0.4.115

During the active Goatman evening, after reaching the campsite, run either operator command:

```text
/ghosthouse vignette goatman plate
/ghosthouse test goatman plate
```

The shortcut puts a cooked, round-bound test frank on every empty current diner's plate. Existing servings keep their actual display UUID, item components and burnt state. The saved cohort determines the count, including a peer who joined since the last scene tick. All places must be loaded and supported, with their original plate displays present, before anything is added.

Once the actual plates are filled, the normal supper gate releases. The scene clock is not jumped: the cousin's departure and return, doorway exchange, knocking, window circuits, admission and dawn continue in their normal order. Use the real door and bathroom window to test either outcome. No Witness credit, vigil time, actor, disguise, tell, inventory, cursor item, pan original or finite cooler pack is changed by preparation.

The command requires permission level 2 and an active participant in a fresh gathering phase. It refuses observers, other scenes, legacy evenings, knocking nights and finished rounds. Repeating it, including after saved-data reload or after somebody eats, never refills a plate or restarts the scene. It does not repair removed furniture. Generated food carries a testing marker; this is an explicit operator fixture, not a new ordinary source of supplies.

Use either status alias to see supper readiness and plate count alongside the existing night diagnostics:

```text
/ghosthouse vignette goatman status
/ghosthouse test goatman status
```

To place the scene for a new test, `/ghosthouse test vignette goatman` places its test door. Enter normally and reach the camp. An already completed personal resolution remains completed; this shortcut does not erase it.
