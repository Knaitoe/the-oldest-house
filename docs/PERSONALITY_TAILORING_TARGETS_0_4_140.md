# Existing vignette moments to tailor later

This follows the [PR review](PR_10_REVIEW_0_4_140.md) and the owner's [House Read document](HOUSE_READ_DESIGN.md). It identifies existing moments and the smallest useful change. It implements no personality state, classifier, overlay or new choice screen. The five quiet rooms still record only their own literal actions.

The first pass should use a few recognizable echoes: the same nighttime object, a stranger's form of address, one place laid at a table. Whole new era-specific furnishing sets would add work without making the connection clearer. Unknown states keep the current scene. The House's writing continues to use the reader's name or “you.”

## Hold these until the supporting scene work exists

- **Family Copy sink:** the saved copy has actual captured household geometry and original metadata (`LiteraryCopies.capture`, `construct`, `sceneTick`). It does not guarantee a suitable bathroom counter or expose a ready-made routine location. Find a real supported surface in that reader's copy; skip the touch if none exists. Never manufacture a bathroom over their house or overwrite a copied chest, original book, projection or edit.
- **Coats/faces on doubles:** keep the real player's skin unchanged. Apply a later coat only to a confirmed House-made image of that player; UNSEEN obscures that copy's face. The existing Missing Sleep CCTV contains a player-skin mimic, but its approved complicity rewrite is still separate work. Do not build a second personality path into the sequence due to be replaced. Backseat's rearview renders its actual rear-cabin monster; it is not a player double and should not inherit the reader's face settings. No existing sleeping-player double has been established in this review, so a wrapped sleeping double remains a future target.
- **Harrigan's phone:** make the reader's spare a portable button handset for ANALOG, with a plainer display, while retaining its clock, contact, calls, texts and voicemail (`scratchTicket`, `phoneState`, `phoneAction`). Choose that appearance when the reader receives their owned original. Keep Harrigan's separate phone, its identity and burial/keepsake choice intact. This needs a matching native item model and phone-screen variant; a ringing hallway landline is a separate later prop. It does not require era-specific furniture throughout the study.
- **RUNAWAY room order:** the exact future hook is `LabyrinthDealer.dealWeight(data, player, place)`, before a fresh eligible deal. Preserve remembered maps, scent, rescue priority, ordinary-hall pacing and existing story dependencies. This is a House-wide change, deferred with the variables.
- **The House of Leaves/account:** `StaircaseProse.compose`, `memory` and `sentence` are the later writing points. This remains deferred. Existing immutable account originals must not change when a later state changes.
- **Mattress, marriage and passenger-seat rooms:** these are planned in the document; this review does not pretend they are implemented vignettes with existing hooks.

Silo's collapse/radio, Backseat's acceleration/crash, the tunnel's pursuit, Layered Man's rescue/tearing, diner consumption and Motion Light's admission/standoff should retain their current physical causes and consequences. None needs a personality-dependent difficulty or resolution to make the House's smaller echoes convincing.

## When implementation is authorized

For a text change, preserve the saved original and show the unchanged fallback for unknown states. For an object or actor change, use the existing private view/owner route, retain its UUID and finite custody, and refresh the same view after reconnect. The decisive check is two actual players seeing their own variation in the same scene without altering each other's dialogue, objects, routes or credit. No new profile API, save schema or category assignment has been added by this inventory.
